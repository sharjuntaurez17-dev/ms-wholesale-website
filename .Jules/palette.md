## 2024-07-03 - Form Labels and Interactive Element Accessibility
**Learning:** In the Splitwork app's mobile-first UI, form inputs are sometimes rendered with separate `<label>` elements but without the structural explicit association (`htmlFor` on the label and `id` on the input). Furthermore, some text-only interactive elements like "Forgot password?" and "Sign up" links are implemented as clickable `<span>` tags, which lacks built-in keyboard accessibility (focusing and spacebar/enter activation).
**Action:** Always verify structural associations between labels and inputs using `htmlFor`/`id`. Convert interactive text spans into native `<button type="button">` tags. Apply the CSS reset `background: "none", border: "none", padding: 0` to maintain the exact visual design while adding critical keyboard accessibility for screen reader and keyboard users.
