## 2026-09-12 - Semantic Interactive Elements & Label Linking
**Learning:** In highly inline-styled applications, interactive elements are often implemented as accessibility-hostile `<span>` tags. Converting these directly to semantic `<button type="button">` with reset styles (`background: "none", border: "none", padding: 0, font: "inherit"`) perfectly preserves the visual design while making the elements natively keyboard-accessible and screen reader friendly. Additionally, explicitly pairing `<label>` elements with their inputs using `htmlFor` and `id` provides necessary context to assistive technologies.
**Action:** When finding clickable `<span>` elements used as links or buttons, convert them to `<button>` elements with CSS resets to improve accessibility without altering visual design. Always verify forms have linked labels and inputs using `htmlFor` and `id`.
