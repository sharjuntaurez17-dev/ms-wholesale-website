## 2024-05-18 - Accessibility improvements in LoginScreen
**Learning:** Found a pattern in this application where interactive text elements (like "Forgot password?" and "Sign up") are implemented as `<span>` tags with `cursor: pointer` rather than native `<button>` or `<a>` elements, making them inaccessible to keyboard navigation. Forms are also missing structural associations between `<label>` and `<input>` using `id` and `htmlFor`. Additionally, dynamic error message containers lack `role="alert"` and `aria-live="polite"` for screen reader announcements.
**Action:** Always convert interactive `<span>` elements to `<button type="button">` using the reset CSS style `background: "none", border: "none", padding: 0, font: "inherit"` to maintain the visual appearance while enabling keyboard accessibility. Explicitly pair `<label>` and `<input>` elements using matching `htmlFor` and `id` attributes. Add `role="alert"` and `aria-live="polite"` to dynamic error containers to ensure they are announced by screen readers.
