## 2024-10-21 - Improve Login Accessibility
**Learning:** React applications often suffer from missing semantic HTML connections (e.g. input/label `id`/`htmlFor` pairings, and interactive elements correctly implemented as `<button>` instead of `<span>`). These are critical for screen reader compatibility and general accessibility.
**Action:** Always ensure that form labels are correctly associated with inputs using `htmlFor` and `id`. Additionally, `role="alert"` should be used on conditional error messages. Always change interactive `<span>` elements (like text-based buttons for "Sign up" or "Forgot password") to native semantic `<button type="button">` using an inline reset style (`background: 'none', border: 'none', padding: 0, font: 'inherit'`) to maintain visual appearance while enabling keyboard accessibility.
