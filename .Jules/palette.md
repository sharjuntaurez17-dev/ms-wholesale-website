## 2025-02-28 - LoginScreen Accessibility Overhaul
**Learning:** This app heavily uses inline styling which led to interactive elements being implemented as inaccessible `<span>` tags (like "Forgot password?" and "Sign up") and inputs missing strict structural associations via `htmlFor` on labels. Additionally, conditionally rendered error messages were missing `role="alert"` preventing screen readers from announcing them immediately.
**Action:** When working on this application, proactively check for unassociated labels and interactive `<span>` tags. Use standard `<button type="button">` or semantic equivalents and apply the style reset `background: "none", border: "none", padding: 0, font: "inherit"` to maintain visual fidelity while ensuring true keyboard and screen reader accessibility. Ensure dynamic error containers utilize `role="alert"` and `aria-live="polite"`.
