## 2024-02-09 - Accessible Form and Interactive Elements in Phone-Frame UI
**Learning:** In highly stylized, inline-style React environments (like this app's PhoneFrame wrapper), interactive elements such as "Forgot password" links and "Sign up" toggles are often incorrectly implemented as inaccessible `<span>` tags. In addition, conditional dynamic error messages can lack structural announcements. Furthermore, while the visual design uses wrapping `<div>`s for spacing form labels and inputs, they are missing structural semantic associations.
**Action:** When adding UX improvements, always convert interactive text elements (e.g., spans functioning as links/buttons) into native semantic elements (`<button type="button">`) with a CSS reset (`background: "none", border: "none", padding: 0, font: "inherit"`) to retain visual fidelity while restoring screen-reader and keyboard accessibility. Always explicitly pair `<label>` and `<input>` using matching `htmlFor` and `id` properties. Always add `role="alert"` and `aria-live="polite"` to conditional error boundaries to announce dynamic updates effectively.
