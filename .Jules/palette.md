## 2024-11-06 - Fixing span-based interactions and validation blocking in React forms
**Learning:** This app heavily uses inline styles and native HTML5 validation (like `required`) can block custom React `onSubmit` handlers. Additionally, developers sometimes use `<span>` for interactive elements (like "Forgot password?") to maintain styling when they should be using `<button>`.
**Action:** When adding HTML5 `required` attributes to inputs that are part of a React form with a custom `onSubmit` handler, add the `noValidate` attribute to the `<form>` tag. This prevents native browser tooltips from stopping the handler. When converting interactive `<span>` tags to `<button>`, use a CSS reset (`background: "none", border: "none", padding: 0, font: "inherit"`) to preserve the inline visual styling while gaining native button accessibility semantics.
