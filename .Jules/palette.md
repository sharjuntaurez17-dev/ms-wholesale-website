## 2024-08-08 - Accessible interactive elements and form associations
**Learning:** Found instances where interactive elements like "Forgot password?" and "Sign up" links were implemented using `<span>` tags. These span tags lacked inherent accessibility capabilities like keyboard navigation or screen reader exposure. Furthermore, form fields lacked associations between `label` elements and corresponding `input` controls.
**Action:** Always ensure that visually interactive components are semantically accessible. If a component visually looks like text but functions as an interactive button/link, use standard native elements (e.g., `<button type="button">`) alongside basic style resets (like `background: "none", border: "none", padding: 0, font: "inherit"`) rather than `<span>`. Additionally, always explicitly link labels to their input fields via matched `htmlFor` and `id` properties.
