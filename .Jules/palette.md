## 2024-05-24 - Accessibility Enhancements on Login Screen
**Learning:** Found multiple instances where interactive text elements were implemented as styled `<span>` tags, which are inaccessible via keyboard navigation. Additionally, form `<label>` and `<input>` elements lacked explicit association, and error messages lacked standard screen reader announcements.
**Action:** When working on UI enhancements in this application, strictly verify that any interactive element utilizes native HTML elements (e.g., `<button type="button">`) with a style reset (`background: "none", border: "none", padding: 0, font: "inherit"`) rather than `<span>` to ensure keyboard accessibility. Also verify form fields use explicit `htmlFor`/`id` linking and dynamic error containers use `role="alert"` and `aria-live="polite"`.
