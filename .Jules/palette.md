## 2024-05-20 - Form Accessibility and Interactive Span Resets
**Learning:** In this UI pattern, form accessibility issues arise from missing `htmlFor`/`id` associations on labels/inputs and lacking ARIA alert roles on dynamic error messages. Additionally, interactive links (like "Forgot password" or "Sign up") implemented as `<span>` tags can be successfully converted to semantic `<button type="button">` tags while preserving exact visual appearance by utilizing inline style resets (`background: "none", border: "none", padding: 0, font: "inherit"`).
**Action:** When working with forms or interactive texts in this design system, automatically associate labels with inputs using `htmlFor`/`id`, add `role="alert"` and `aria-live="polite"` to error state containers, and consistently convert interactive `<span>`s to `<button>`s using the inline style reset pattern to ensure robust keyboard accessibility.
