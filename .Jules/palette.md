## 2024-07-10 - Form Structural Associations and Interactive Span Elements
**Learning:** In this application, interactive text links (like "Forgot password?" and "Sign up") are often implemented using `<span>` tags with inline styles instead of semantic buttons or anchors. Additionally, form labels are sometimes missing explicit structural associations (`htmlFor` / `id` pairs) with their inputs.
**Action:** When working on form accessibility and keyboard interactions, proactively check and convert interactive `<span>`s into `<button type="button">` using a CSS style reset (`background: "none", border: "none", padding: 0, font: "inherit"`) to ensure keyboard accessibility while preserving the exact visual appearance. Also, verify that explicit `<label>` associations are present.
