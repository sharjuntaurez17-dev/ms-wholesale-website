## 2024-10-28 - Explicit Form Label Association and Alert Roles
**Learning:** This application's specific form structures tend to lack explicit association between inputs and labels. Even with custom React validation preventing default HTML5 validation submission, we can safely improve standard accessibility by linking elements explicitly and keeping `required` flags. Additionally, custom dynamic React error states in conditional forms require the `role="alert"` and `aria-live="polite"` attributes to be reliably announced by screen readers when they pop up. We must use `noValidate` on the form to allow the React `onSubmit` event to handle the conditionally required checking logic properly on empty submits to show those custom errors during testing.
**Action:** When working on form components in this repository, always ensure `<label>` and `<input>` elements are explicitly linked via `htmlFor` and `id`, standard validation properties (`required`, `aria-required`) are populated, and any dynamically appearing error wrappers include `role="alert"` and `aria-live="polite"`. Add `noValidate` to forms running custom error React handlers.
