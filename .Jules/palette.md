## 2024-11-20 - Semantic Navigation in Inline-Styled Apps
**Learning:** React applications utilizing extensive inline-styling often implement interactive, non-navigational actions (like "Forgot password?" or modal toggles) using `<span>` elements with `cursor: "pointer"` instead of `<button>` elements to avoid default browser button styling interfering with the layout. This breaks keyboard accessibility because spans cannot receive focus by default and lack semantic meaning for screen readers.
**Action:** When improving interaction accessibility, always convert click-bound `<span>` tags acting as buttons into native `<button type="button">` elements. Apply a CSS style reset (`background: "none", border: "none", padding: 0, font: "inherit"`) directly to the inline style object to nullify default button styles, seamlessly maintaining the visual design while instantly granting keyboard navigation (tabbing) and screen reader support.
