## 2024-05-18 - Semantic Link Replacements in Mobile Frames\n**Learning:** Interactive elements designed to look like simple text links (e.g., "Forgot password?", "Sign up") are frequently implemented as `<span>` tags with `cursor: pointer` rather than native interactive elements, completely breaking keyboard tabbing and screen reader support.\n**Action:** Always replace these with `<button type="button">` or `<a>` elements, using the CSS reset `background: "none", border: "none", padding: 0, font: "inherit"` to ensure visual parity while restoring accessibility.
