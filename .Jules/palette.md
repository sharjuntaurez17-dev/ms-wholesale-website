## 2023-10-24 - Form Accessibility and Semantic Elements
**Learning:** React elements utilizing inline styles and cursor changes for interactivity (such as "Forgot password" or "Sign up" links) are commonly built with static `<span>` elements, breaking screen reader interaction and keyboard accessibility. Furthermore, inputs lack programmatic association with labels when structural nesting is absent.
**Action:** Always refactor static interactive UI components (like `<span>`) into native, semantic `<button type="button">` or `<a>` elements using the CSS reset `background: "none", border: "none", padding: 0, font: "inherit"` to ensure correct tab ordering and screen reader announcement while keeping visual fidelity intact. Explicitly add matching `htmlFor` and `id` properties to form inputs. Add `role="alert"` and `aria-live="polite"` to conditional error rendering containers.
