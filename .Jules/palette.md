## 2024-05-18 - Convert Interactive Spans to Buttons
**Learning:** Due to heavy reliance on inline styles, many interactive elements (like "Forgot password?" and "Sign up") were built using `<span>` tags. These elements are inaccessible to keyboard users and screen readers, hiding important navigation and functionality.
**Action:** When working on this application, always convert interactive `<span>` tags that trigger actions to semantic `<button type="button">` or `<a>` tags. Apply CSS reset styles (`background: "none", border: "none", padding: 0`, and explicit `font: "inherit"`) to maintain the existing visual appearance while making them accessible. Also always ensure `<label>` and `<input>` elements are explicitly linked via `htmlFor` and `id` as this is also a recurring problem.
