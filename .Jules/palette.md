## 2024-11-10 - React custom validation versus native HTML5 form validation
**Learning:** When using Playwright to test React custom error messages on forms, adding native HTML5 `required` attributes will prevent the form's `onSubmit` handler from firing if the fields are empty. To test custom React validation logic and error messages, you must either satisfy native validation (e.g., by filling fields) or add `noValidate` to the `<form>` element to prevent native browser validation tooltips from blocking the `onSubmit` handler while maintaining semantic accessibility.
**Action:** When adding native HTML5 `required` attributes to inputs in forms with custom React `onSubmit` validation logic, always add the `noValidate` attribute to the `<form>` element to prevent native browser validation tooltips from blocking the `onSubmit` handler while maintaining semantic accessibility.
