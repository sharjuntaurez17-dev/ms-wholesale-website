## 2023-11-02 - Interactive spans needing conversion to buttons
**Learning:** Found a pattern in this application where interactive elements (like "Forgot password?" and "Sign up" links) are implemented as `<span>` tags with `cursor: "pointer"` rather than native interactive elements like `<button>`. This completely breaks keyboard accessibility, as `<span>` elements cannot receive focus by default or be activated with Enter/Space keys without extensive custom ARIA and key handlers.
**Action:** Always convert these interactive `<span>` tags into native `<button type="button">` or `<a>` elements. To maintain the existing visual design and prevent unwanted default button styling (like backgrounds and borders), apply inline CSS resets (`background: "none", border: "none", padding: 0, font: "inherit"`) to the new button elements.
