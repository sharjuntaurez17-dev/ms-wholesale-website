## 2024-05-24 - Accessibility improvements on login screen
**Learning:** Found that `<label>` tags were missing `htmlFor` structural associations with their `<input>` fields. Furthermore, interactive text links like "Forgot password?" and "Sign up" were implemented as clickable `<span>` elements, breaking keyboard accessibility and screen reader interaction. Conditional error messages were also missing `role="alert"` for proper screen reader announcements.
**Action:** Always pair `<label>` and `<input>` using matching `htmlFor` and `id` attributes. Use native interactive elements like `<button type="button">` (with CSS reset styles `background: "none", border: "none", padding: 0, font: "inherit"`) instead of `<span>` for text-based actions to preserve styling while ensuring keyboard support. Ensure conditional error states implement `role="alert"` and `aria-live="polite"`.
