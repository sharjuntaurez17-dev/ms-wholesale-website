## 2024-05-24 - Login Form Accessibility Improvement
**Learning:** Native form validation in React applications is often bypassed in favor of custom state-based validation. However, omitting native validation attributes (like `required`) and structural `<label>` associations (`htmlFor` mapping to `id`) severely degrades the experience for screen reader users. Screen readers rely on these structural relationships to properly announce form controls and their requirements. Also dynamically rendered error messages will not be read aloud unless properly tagged with aria-live regions.
**Action:** Always ensure that form inputs have structurally associated `<label>` elements via `htmlFor`/`id` pairs, include `required` and `aria-required="true"` where appropriate, and use `noValidate` on the `<form>` to allow React validation to run while preserving the semantic HTML5 structure. Always tag dynamically appearing error message containers with `role="alert"` and `aria-live="polite"`.
