## 2024-08-03 - Form Pairing and Semantic Interactive Elements
**Learning:** This application relies heavily on inline styles for visual polish, occasionally resulting in accessible patterns being missed, such as form inputs lacking paired IDs (`htmlFor`/`id`) and interactive text items (like "Forgot password?" and "Sign up" links) being implemented as `<span>` tags. Dynamic errors also initially missed `role="alert"` formatting.
**Action:** Always verify form inputs are correctly paired with labels via `htmlFor` and `id`, ensure interactive elements use native semantic tags (like `<button type="button">`) leveraging the CSS reset `background: "none", border: "none", padding: 0, font: "inherit"`, and add proper roles (`role="alert" aria-live="polite"`) to dynamic error containers.
