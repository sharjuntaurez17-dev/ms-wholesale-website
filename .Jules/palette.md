## 2024-10-18 - Semantic elements and structural associations
**Learning:** In this application, interactive elements like "Forgot password?" or "Sign up" are frequently implemented as inaccessible `<span>` elements with `cursor: "pointer"` instead of proper semantic buttons or links. Additionally, form structures are occasionally incomplete, lacking associations between `<label>` and `<input>` elements.
**Action:** Always convert interactive `<span>` elements to semantic native elements like `<button type="button">` or `<a>`. Use the style reset `background: "none", border: "none", padding: 0, font: "inherit"` to maintain visual appearance while fixing keyboard focus and accessibility. When encountering forms, explicitly associate labels and inputs using matching `htmlFor` and `id` attributes, and add `required` and `aria-required="true"` where appropriate.
