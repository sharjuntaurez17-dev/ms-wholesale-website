## 2024-05-24 - Accessibility Patterns in Inline Styles\n**Learning:** The application's heavy reliance on inline styles often leads to pseudo-interactive elements (like spans used for 'Forgot password') that lack semantic meaning and keyboard focus. Adding structural ARIA roles or converting to native elements requires a strict CSS reset (`background: none, border: none, padding: 0, font: inherit`) to prevent visual regressions while enabling accessibility.\n**Action:** When auditing forms, actively look for interactive text elements and convert them to `<button type="button">` with the CSS reset, rather than just adding click handlers to spans.
