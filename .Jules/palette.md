## 2024-11-05 - Form Accessibility and Semantic Elements
**Learning:** In this application, forms sometimes lack structural accessibility associations (e.g. `htmlFor` and `id`), and interactive elements (like "Forgot password" or "Sign up") are implemented as non-semantic `<span>` tags. Additionally, form validation error messages may lack screen reader announcements.
**Action:** When working on forms, ensure labels are paired with inputs via `htmlFor`/`id`, add `required` and `aria-required="true"`, include `noValidate` on the `<form>` to prioritize custom validation, convert interactive `<span>` tags to `<button type="button">` or `<a>` with a CSS style reset (`background: "none", border: "none", padding: 0, font: "inherit"`), and add `role="alert"` and `aria-live="polite"` to dynamic error message containers.
