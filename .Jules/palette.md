## 2024-08-24 - Accessibility Enhancements in Login Screen\n**Learning:** Interactive elements such as "Forgot password?" and "Sign up" were implemented using `<span>` tags, which are inherently not keyboard focusable, breaking a11y standards. Furthermore, form fields lacked semantic `id`/`htmlFor` associations.\n**Action:** Use native `<button type="button">` tags for interactive text-only triggers, paired with CSS resets (`background: "none", border: "none", padding: 0, font: "inherit"`) to preserve intended visual design while ensuring full keyboard accessibility. Always pair labels and inputs using structural ARIA attributes.
