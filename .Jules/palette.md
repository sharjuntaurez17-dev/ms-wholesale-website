## 2024-05-24 - Accessibility improvements for inline styles
**Learning:** The application uses inline styles extensively. It is easy to miss semantic HTML structure, like form labels tied to inputs with `htmlFor` and `id`, and proper error attributes like `role="alert"` and `aria-live="polite"`. It is also common for interactive elements like "Forgot password" to be implemented as a non-interactive `<span>` element.
**Action:** Always convert non-interactive `<span>` interactive elements to native semantic elements like `<button type="button">` or `<a>` and apply the CSS style reset `background: "none", border: "none", padding: 0, font: "inherit"` to maintain existing visual appearance while enabling keyboard accessibility. Explicitly pair `<label>` elements with their respective `<input>` elements using matching `htmlFor` and `id` attributes. Use `role="alert"` and `aria-live="polite"` on conditional form error message containers.
