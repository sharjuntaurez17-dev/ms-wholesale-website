## 2024-05-21 - Form Label Accessibility and Keyboard Focus\n**Learning:** Discovered a pattern in the Login component where interactive links ("Forgot password", "Sign up") were implemented as non-focusable `<span>` tags, and inputs lacked explicit `<label>` association via `id`/`htmlFor`.\n**Action:** Replaced `<span>` elements acting as links with semantic `<button type="button">` tags for proper keyboard focus, and linked form labels to inputs using `htmlFor`.
